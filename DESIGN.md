# Design Direction — Is My PC On?

## World

A premium power-assurance bureau rendered like an old instrumentation department that hired a very expensive editorial designer. The interface acts gravely; the copy lets the visitor in on the joke.

## Surface: `/` · Persuade + Operate

- First viewport: a direct, oversized question and one clear action face a precisely drawn diagnostic console. No pre-headline eyebrow.
- Visitor path: ask → run the mock diagnostic → see “YES.” → discover the fictional plans.
- Signature moment: the console calmly scans, the warm amber indicator resolves to acid green, and “YES.” arrives with editorial weight.
- Phone composition: headline, action, and outcome lead; the instrument scales down and remains secondary.
- Honest risk: the deadpan treatment could read as a real diagnostic. Counter this with “we do not inspect your hardware” and an explicit parody note near pricing.

## Visual System

- Surfaces: warm paper `#F2F0E8`; instrument face `#202523`; muted panel `#DEDCD2`.
- Ink: near-black `#202523`; supporting text `#555E59`.
- Signal colors: kiln orange `#BB4E31`; power-on green `#C9E96C`; use with dark text for contrast.
- Typography: self-hosted Noto Serif Bold for the main voice; self-hosted Red Hat Text for navigation, body, controls, and interface labels. Use monospace only for actual measurements.
- Composition: editorial asymmetry, generous margins, rules and aligned labels. Pricing is an open ledger, not repeated cards. Avoid gradients and ornamental grids.
- Motion: one short diagnostic/result sequence. Keep the idle page still, respect reduced motion, and never delay repeat use.

## Quality Contract

1. The exact question and Run diagnostics action are apparent immediately.
2. The finished answer is the strongest object in the result state, followed by the monthly-free-check line.
3. The mobile state says “Sir, this is a phone.” when the best-effort device test signals a phone.
4. Prices, fake checkout, Enterprise theatre, and lack of hardware access are clearly honest.
5. The 375px, 768px, and 1440px layouts keep the full copy readable with no horizontal overflow.
6. Keyboard, Escape, focus return, reduced motion, and repeated checks work without network or form submission.
