# Is My PC On?

A static React, Vite, and TypeScript parody site. Install the local package dependencies, start the Vite development server, and run the build and test scripts from the project directory.

All diagnostics are theatrical and local. The site never inspects your computer or transmits data. The free check is never enforced and can always be replayed. Checkout and sales are fictional interactions with no payment or contact submission.

Local fonts: Noto Serif (OFL) and Red Hat Text (SIL OFL), bundled in public/fonts with their license files.
