# Is My PC On?

A static React, Vite, and TypeScript site. Install the local package dependencies, start the Vite development server, and run the build and test scripts from the project directory.

The page does not inspect your computer or transmit diagnostic data. Its status sequence does not determine whether your PC is on, and the result remains locked. Pro is listed at ₱99/month; Enterprise pricing is custom. Online checkout and sales contact are not available yet.

Local fonts: Noto Serif (OFL) and Red Hat Text (SIL OFL), bundled in public/fonts with their license files.
